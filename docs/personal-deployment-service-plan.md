# 个人用户代码交付方案

目标：向个人用户销售可自行部署在其 Muse 环境中的代码。交付范围和版本以购买时的约定为准。

## 交付内容

- 指定版本的完整代码包及安装说明。
- [微信和企业微信使用教程](wechat-wecom-muse-guide.md)，以及仓库中相应的配置示例和故障排查文档。
- 明确告知版本、依赖及已知限制。默认 legacy 路径与实验性的 SQLite core 应分别说明，不能把尚未完成真实平台验收的 core 说成完整可用。

## 交付前检查

1. 从确定的 commit 制作代码包，检查包含安装必需的源码、配置示例、许可证和文档，不包含凭证、用户数据、运行状态或虚拟环境。
2. 按安装文档在隔离环境检查所售版本能否安装，并记录实际验证过的渠道、功能和未验证项。真实 Muse 环境测试与本地模拟测试分别说明。
3. 说明代码的运行环境、客户需自行准备的账号及凭证、是否包含更新或技术支持，以及明确的交付方式和价格。这些以销售时的实际约定为准。
4. 当前仓库采用 MIT 许可证，分发时保留版权和许可声明。个人微信、企微、Muse 及其他第三方服务能否用于具体商业用途，需要分别核实其适用条款；不能把仓库许可证理解为对这些服务的授权。

## 下一步

选择首个交付版本，并将可重复的打包和安装检查流程落地；按实际测试结果编写简短的购买与使用说明。
